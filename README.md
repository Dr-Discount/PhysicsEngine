# Physics Engine
a simple physics engine that allows you (the user) to create circlur bodys and move them around with effectors or connect hem with springs.

# Effectors
 - point-effector: pushes or push to a specific point is space
 - gravitional: makes bodies in the circle gravtate twords each other
 - Area: pushs object in a specific direction based on the angle
 - Drag: slows down greatly any body that enters

# How to Instal
click on the code option on the top of the page and download was a zip
unzip the porject and open the solution in vs code 2022
click run when project is loaded

# How to Use
use the sliders on the left to adjust he effectors and bodys made
press left click to add a body to the world
press right middle moude button the add the effector chosin in the drop down to the world
hold right click over a body and drag your mouse to another to crate a spring connecting the two
